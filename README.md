# Carpeta técnica · Taller de Electricidad 2.° año

Página para los alumnos: https://rodolfoemanuelduran-dotcom.github.io/carpeta-electricidad/

El QR del aula apunta a esa dirección. La página tiene dos botones, uno para abrir el PDF y otro para descargarlo, y muestra la fecha de la última actualización.

## Cómo actualizar el PDF sin cambiar el QR

1. Prepará el PDF nuevo y ponele exactamente este nombre: `carpeta-tecnica.pdf`.
2. En este repositorio, entrá en **Add file → Upload files**, arrastrá el PDF y tocá **Commit changes**. El archivo nuevo reemplaza al anterior.
3. En uno o dos minutos la página ya ofrece la versión nueva, con la fecha actualizada.

## No cambiar

- El nombre del repositorio, `carpeta-electricidad`.
- El nombre del archivo, `carpeta-tecnica.pdf`.
- El archivo `index.html`.

Si cambia cualquiera de los tres, el QR deja de funcionar.

## Archivos

- `index.html`: la página que abre el QR.
- `carpeta-tecnica.pdf`: la carpeta técnica.
- `logo-red.jpg`: logo R.E.D. Es la imagen que se ve al compartir el enlace por WhatsApp.
- `.nojekyll`: hace que GitHub publique los archivos tal como están.
